## 九、关键交互设计

### 9.1 阅读器界面布局

```
┌──────────────────────────────┐
│ ← 书名               目录 设置 │  ← 顶部栏（点击中央区域唤出）
├──────────────────────────────┤
│                              │
│      章节正文渲染区域           │
│     （Canvas / WebView）       │
│                              │
├──────────────────────────────┤
│         第 128 章 / 共 520 章  │  ← 底部进度条
└──────────────────────────────┘
```

### 9.2 手势操作

| 手势         | 动作                       |
| ------------ | -------------------------- |
| 点击左侧 1/3 | 上一页                     |
| 点击右侧 1/3 | 下一页                     |
| 点击中间 1/3 | 唤出菜单（目录/设置/亮度） |
| 左右滑动     | 翻页（带动画）             |
| 上下滑动     | 滚动模式翻页               |
| 长按         | 无（防误触）               |

### 9.3 设置面板

- 字体大小：滑块调节（12-24px）
- 字体：系统默认/宋体/楷体/等宽
- 行距：1.2 / 1.5 / 1.8 / 2.0
- 背景：白天白 / 护眼绿 / 夜间黑 / 羊皮纸
- 翻页：仿真翻页 / 覆盖 / 无动画 / 上下滚动
- 亮度：系统/手动滑块
- 自动翻页：关 / 5s / 10s / 15s / 30s
