# 🚀 快速开始 - 客户端网盘解析

## 一分钟配置指南

### 步骤 1：获取夸克 Cookie

1. 打开 https://pan.quark.cn 并登录
2. 按 F12 打开开发者工具
3. 刷新页面，点击任意请求
4. 找到 Request Headers → Cookie
5. 复制这 4 个关键字段（用分号和空格分隔）：

```
__puus=xxx; __kps=xxx; __ktd=xxx; __uid=xxx
```

### 步骤 2：配置 Cookie

打开 `src/utils/pan-config.js`，粘贴你的 Cookie：

```javascript
export default {
  quark: {
    cookie: '__puus=你的值; __kps=你的值; __ktd=你的值; __uid=你的值',
    cookieUrl: ''
  },
  baidu: {
    cookie: '',
    cookieUrl: ''
  }
};
```

### 步骤 3：测试

```bash
npm run dev:h5
```

打开浏览器，点击任意书籍的"在线阅读"按钮。

**成功标志**：
- 控制台显示：`客户端解析网盘链接成功: https://...`
- 页面正常显示书籍内容

**失败情况**：
- 如果提示"网络错误"，检查 Cookie 是否正确
- 如果自动回退到 CDN，说明网盘解析失败但 CDN 可用

---

## ⚠️ 重要提醒

1. **Cookie 安全**：不要将 `pan-config.js` 提交到 Git
2. **Cookie 有效期**：通常 1-2 周，过期需重新获取
3. **小程序配置**：需在微信公众平台添加 `drive-pc.quark.cn` 为合法域名

## 🔄 工作原理

```
readUrl (网盘链接) 
    → 客户端解析 API 
    → 临时直链 
    → 直接下载正文
    
失败时自动回退到 CDN 地址
```

## 💡 提示

- 如果你有服务器，建议用 `cookieUrl` 方式动态获取 Cookie
- 这样 Cookie 更新无需重新打包发布应用
