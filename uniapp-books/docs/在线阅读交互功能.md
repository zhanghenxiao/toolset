**核心代码：**
```javascript
// 区域点击判断
onContentTap(e) {
  const screenWidth = uni.getSystemInfoSync().screenWidth;
  const tapX = e.detail.x;
  
  if (tapX < screenWidth / 3) {
    // 左侧1/3 - 上一章
    this.prevChapter();
  } else if (tapX > screenWidth * 2 / 3) {
    // 右侧1/3 - 下一章
    this.nextChapter();
  } else {
    // 中间1/3 - 切换菜单
    this.toggleMenu();
  }
}

// 滑动手势
onTouchStart(e) {
  this.touchStartX = e.touches[0].pageX;
  this.touchStartTime = Date.now();
}

onTouchEnd(e) {
  const deltaX = e.changedTouches[0].pageX - this.touchStartX;
  const duration = Date.now() - this.touchStartTime;
  
  if (Math.abs(deltaX) > 50 && duration < 300) {
    if (this.pageFlipMode === 'swipe') {
      deltaX > 0 ? this.prevChapter() : this.nextChapter();
    }
  }
}
```

## 🚀 使用方法

### 进入在线阅读

1. 在书籍详情页点击「在线阅读」按钮
2. 系统自动跳转到 `pages/reader/reader`
3. 传递参数：`bookId={book.id}`

### 基本操作

- **翻页：** 点击屏幕左右两侧或左右滑动
- **显示菜单：** 点击屏幕中央
- **打开目录：** 点击顶部「目录」按钮
- **打开设置：** 点击顶部「设置」按钮
- **返回：** 点击顶部左侧返回图标

### 自定义设置

1. 点击「设置」按钮打开设置面板
2. 调整字体、行距、背景等
3. 设置自动保存，下次生效
