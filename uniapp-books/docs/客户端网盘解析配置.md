# 客户端网盘解析配置指南

由于云服务已停服，网盘直链解析功能已迁移到客户端实现。

## 📁 相关文件

- `src/utils/pan-parser.js` - 网盘解析核心逻辑
- `src/utils/pan-config.js` - Cookie 配置文件（已加入 .gitignore）
- `src/pages/reader/reader.vue` - 在线阅读页面（调用解析功能）

## 🔧 配置步骤

### 1. 获取夸克网盘 Cookie

1. 登录 https://pan.quark.cn
2. 打开浏览器开发者工具（F12）
3. 切换到 **Network** 标签
4. 刷新页面
5. 点击任意请求，找到 **Request Headers**
6. 复制 `Cookie` 字段的完整内容

**关键字段（精简版）**：
```
__puus=xxx; __kps=xxx; __ktd=xxx; __uid=xxx
```

### 2. 配置 Cookie

编辑 `src/utils/pan-config.js`：

```javascript
export default {
  quark: {
    // 方式1：直接配置 Cookie
    cookie: '你的完整Cookie或精简Cookie',
    
    // 方式2：通过接口获取（推荐）
    cookieUrl: 'https://toolset.site/api/get-quark-cookie'
  },
  
  baidu: {
    cookie: '',
    cookieUrl: ''
  }
};
```

### 3. Cookie 动态获取（推荐）

如果你有服务器，可以搭建一个简单的 Cookie 服务：

**Node.js 示例**：
```javascript
// server.js
const express = require('express');
const app = express();

app.get('/api/get-quark-cookie', (req, res) => {
  // 从数据库或文件读取最新 Cookie
  const cookie = readCookieFromDatabase();
  res.send(cookie);
});

app.listen(3000);
```

**配置**：
```javascript
cookieUrl: 'https://your-server.com/api/get-quark-cookie'
```

优势：
- Cookie 更新无需重新打包发布
- 更安全（不在客户端暴露完整 Cookie）
- 可以统一管理多个用户的 Cookie

## 📱 工作流程

```
用户点击"在线阅读"
    ↓
读取 book.readUrl（如 https://pan.quark.cn/s/xxx）
    ↓
调用 parseNetdiskUrl() 解析
    ↓
判断网盘类型（夸克/百度）
    ↓
获取 Cookie（配置文件或接口）
    ↓
调用网盘 API 获取直链
    ↓
返回临时下载地址
    ↓
客户端直接下载正文
    ↓
解析章节并显示
```

## 🔐 安全注意事项

### Cookie 保护

1. **不要提交到 Git**
   - `pan-config.js` 已加入 `.gitignore`
   - 提交前检查是否包含 Cookie

2. **定期更新**
   - Cookie 通常 1-2 周后过期
   - 过期后重新获取并更新配置

3. **权限控制**
   - 如果使用 `cookieUrl`，确保接口有鉴权
   - 防止 Cookie 被他人滥用

### 限流保护

夸克/百度网盘可能有调用频率限制：

1. **客户端缓存**
   - 解析成功后缓存直链（有效期内）
   - 避免重复解析同一文件

2. **用户提示**
   - 解析失败时友好提示
   - 建议用户稍后重试

## 🐛 常见问题

### Q1: Cookie 失效怎么办？

**现象**：解析失败，返回 "未配置夸克网盘 Cookie" 或 "获取分享详情失败"

**解决**：
1. 重新获取 Cookie
2. 更新 `pan-config.js` 中的配置
3. 如果使用 `cookieUrl`，更新服务器端的 Cookie

### Q2: 解析超时

**现象**：加载很久后提示"网络错误"

**原因**：
- 网盘 API 响应慢
- Cookie 已过期
- 网络环境不稳定

**解决**：
1. 检查 Cookie 是否有效
2. 增加超时时间（在 `uni.request` 中修改 `timeout`）
3. 添加重试机制

### Q3: 小程序中无法请求网盘 API

**现象**：提示 "不在以下 request 合法域名列表中"

**解决**：
在微信公众平台配置服务器域名：
- `https://drive-pc.quark.cn`
- `https://pan.baidu.com`

### Q4: 回退到 CDN 失败

**现象**：网盘解析失败后，CDN 也无法访问

**解决**：
1. 检查 `downloadUrl` 配置是否正确
2. 确保 CDN 文件存在
3. 在微信公众平台配置 CDN 域名为合法域名

## 🔄 回退策略

代码已实现多级回退：

```javascript
// 策略1：网盘直链（优先）
if (book.readUrl) {
  contentUrl = await parseNetdiskUrl(book.readUrl);
}

// 策略2：CDN 地址（回退）
if (!contentUrl) {
  contentUrl = book.contentUrl 
    || book.ossUrl 
    || bookTxtUrl(book.downloadUrl);
}

// 策略3：错误提示
if (!contentUrl) {
  throw new Error('无法获取书籍正文地址');
}
```

## 📊 性能优化

### 1. 直链缓存

解析成功后缓存直链，避免重复请求：

```javascript
// 缓存 key: book.readUrl
// 缓存 value: { url, expires }
const cached = uni.getStorageSync(`netdisk_${bookId}`);
if (cached && Date.now() < cached.expires) {
  return cached.url;
}
```

### 2. 并发控制

限制同时解析的请求数量，防止触发限流。

### 3. 预加载

在列表页预解析热门书籍的直链，提升打开速度。
