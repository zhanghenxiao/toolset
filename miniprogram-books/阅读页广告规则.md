# 阅读页广告规则（uniapp-books）

> 适用范围：阅读正文页 `src/pages/reader/reader.vue` 内的广告行为。
> 配置来源：`src/utils/ad-config.js`（本地常量 / 兜底）、`src/utils/remote-config.js`（远程 `app-version.json` 的 `ad` 段，可热更新）。
> 广告 SDK：uni-ad（信息流 `<ad>`、插屏 `<ad-interstitial>`、激励视频 `<ad-rewarded-video>`）。
>
> **注意**：以下「默认」一律以 `ad-config.js` 当前取值为准；部分本地兜底是测试用的短值，线上实际生效值以远程 `app-version.json` 的 `ad` 段为准（已部署 `rewardReaderFirstMinutes:15`、`rewardReaderIntervalMinutes:30`）。

## 总览

| 广告类型 | 展现形式 | 当前开关 | 触发方式 |
|---|---|---|---|
| 信息流（feed） | 内嵌正文分页，**非弹窗** | `readerFeedAdEnabled=true`（开） | 指定章节正文中间自动插入 |
| 插屏（interstitial） | 弹窗 | `AD_INTERSTITIAL_ENABLED=false`（**完全关闭**） | 已改为「章末跳转到本章已有的信息流广告页」 |
| 激励视频（rewarded） | 全屏视频 | 开 | 累计阅读时长达里程碑主动弹 / 用户点「看广告解锁」 |
| 免广告时段 | — | — | 看完激励后 30 分钟内免所有广告 |

---

## 一、信息流广告（正文内嵌，非弹窗）

- **开关**：`readerFeedAdEnabled`（默认 `true`）。
- **不插入的条件**：
  - 处于免广告时段（`isAdFree`）时不插入；
  - 首章分页就绪前（`adReady` 首次置位前）不插入，之后章节才允许。
- **章节门槛**（同时满足）：
  - `chapterNum > AD_FEED_START_CHAPTER(2)`；
  - `(chapterNum - 2) % feedEveryChapter === 0`。
  - `feedEveryChapter` 来自远程 `app-version.json.ad.feedEveryChapter`，经 `clampInt(1, 50)` 兜底到本地 `AD_FEED_EVERY_CHAPTER`。
  - **默认行为**：本地 `AD_FEED_EVERY_CHAPTER = 2` → 在**第 4、6、8、10… 章**插入（非注释里写的第 5、8、11…；见文末备注）。
- **插入位置**：本章正文中间 `floor(页数/2)`，避免与章末 / 翻章断点冲突。
- **前提**：本章分页页数 `>= 2`（否则无「中间页」可插）。
- **广告位**：从 `AD_FEED_PID_LIST` 随机取 `adpid`（正式环境多池兜底）。

---

## 二、插屏广告

- `AD_INTERSTITIAL_ENABLED = false` → **完全关闭**，所有插屏触发点（章末 / 返回书架 / 首页二次）均已拦截，不再弹窗。
- 原「章末 / 返回书架」弹插屏，已**改为「跳转到本章已有的信息流广告页」**：
  - 触发：`maybeShowChapterEndFeedAd` 在 `chapterNum % AD_INTERSTITIAL_EVERY_CHAPTER(5) === 0`（第 5、10、15… 章）翻完后，尝试跳到下一章的信息流广告页；
  - 若下一章无广告页则不放。

---

## 三、激励视频（rewarded video）

### 3.1 主动触发（累计阅读时长里程碑）
- 阈值（远程可配，单位分钟）：
  - 首次：`rewardReaderFirstMinutes` → 本地兜底 `AD_REWARD_READER_TIME_MS`（=30s 测试值）；
  - 之后间隔：`rewardReaderIntervalMinutes` → 本地兜底 `AD_REWARD_READER_INTERVAL_MS`（=90s 测试值）。
  - 线上已部署 `15` / `30` 分钟。
- 累计阅读时长**跨会话持久化**于 `reader_reading_time_v1 { total, next, ... }`，每 10s 落盘 + `onHide/onUnload` 落盘；页面在后台不计入时长。
- 每 10s 由 `checkReaderTimeReward` 检测；**只有真正展示成功（isEnded）才推进里程碑**；
  - 被频控 / 组件未就绪 / 无填充导致未展示 → 间隔 `AD_REWARD_RETRY_MS(60s)` 重试，不算用户放弃、**不锁定**。
- 免广告期内不弹，触发机会保留到窗口结束后。

### 3.2 未完整观看 → 锁定后续章节
- `AD_REWARD_LOCK_CHAPTERS = true`：达到里程碑弹广告后，**若未完整观看（中途关闭 / 未看完）**：
  - 锁定后续章节——`nextChapter` / 章末翻页 / 目录跳转 / 进度条 / 自动翻页 **全部拦截**，必须完整观看一次激励视频（解锁弹窗或「免广告」按钮）才能继续读。
- 锁定状态**跨会话 / 跨书籍持久化**（`lockedChaptersByBook` 按书分别记账，避免章节号串号）：
  - 到达里程碑那一刻即记录锁定边界并落盘，故「弹广告途中 kill 进程」后重新进入任意书籍正文仍保持锁定并**自动重新弹**激励视频；
  - 只有完整看完（`isEnded`）才解除锁定并推进里程碑。
- 已主动弹过且被中途关闭（`rewardAutoOffered`）后**不再自动弹**，仅保留解锁弹窗。

### 3.3 用户主动「看广告解锁」
- 点击「看广告解锁」：完整看完（`isEnded`）→ 赠送 `AD_REWARD_AD_FREE_MS(30 分钟)` 免广告（`onRewardUnlock`，`adFreeUntil` 持久化本地）。
- 频控：`AD_REWARD_INTERVAL(5 分钟)`；`onRewardUnlock` 用 `force` 忽略频控，主动触发走默认频控。

### 3.4 其它触发点（当前关闭）
- 首页 / 详情主动触发：`AD_REWARD_ON_DETAIL=false`、`AD_ENABLE_SECONDARY=false` → 暂不启用。

---

## 四、免广告时段（isAdFree）

- 看完激励后 `adFreeUntil = now + 30 分钟`（`AD_REWARD_AD_FREE_MS`），持久化。
- 免广告期内：
  - 不插入信息流广告；
  - 不跳信息流广告页；
  - 不弹任何激励视频。

---

## 五、可调参数一览

| 参数（ad-config.js） | 含义 | 默认值 | 远程覆盖 |
|---|---|---|---|
| `AD_FEED_START_CHAPTER` | 前 N 章不插信息流 | `2` | — |
| `AD_FEED_EVERY_CHAPTER` | 每 N 章插 1 条信息流 | `2` | `app-version.json.ad.feedEveryChapter`（clamp 1–50） |
| `AD_INTERSTITIAL_ENABLED` | 插屏总开关 | `false` | — |
| `AD_INTERSTITIAL_EVERY_CHAPTER` | 章末跳广告页的章间隔 | `5` | — |
| `AD_REWARD_AD_FREE_MS` | 看完激励的免广告时长 | `30 分钟` | — |
| `AD_REWARD_READER_TIME_MS` | 首次主动弹激励的阅读时长 | `30000`（30s 测试值） | `rewardReaderFirstMinutes`（分钟） |
| `AD_REWARD_READER_INTERVAL_MS` | 之后每次间隔 | `90000`（90s 测试值） | `rewardReaderIntervalMinutes`（分钟） |
| `AD_REWARD_LOCK_CHAPTERS` | 未看完是否锁章 | `true` | — |
| `AD_REWARD_INTERVAL` | 两次激励最小间隔 | `5 分钟` | — |
| `AD_REWARD_RETRY_MS` | 未展示成功重试间隔 | `60s` | — |
| `AD_USE_TEST` | 总开关（true=测试广告位） | `false` | — |
| `AD_ENABLE_SECONDARY` | 次要广告（插屏/信息流） | `false` | — |
| `AD_REWARD_ON_DETAIL` | 详情页激励 | `false` | — |

## 六、已知不一致 / 备注

1. `reader.vue` 顶部注释称「`feedEveryChapter` 默认 5，第 5、8、11、14… 章插入」，但 `ad-config.js` 当前 `AD_FEED_EVERY_CHAPTER = 2`，实际为**第 4、6、8、10… 章**。本文档以代码（`ad-config.js`）为准，注释已过时，需时同步。
2. 本地兜底阈值（`30s` / `90s`）为测试短值；线上以远程 `app-version.json` 的 `ad` 段（`15min` / `30min`）为准，无需改代码即可调。
3. 插屏虽关闭，但其「章末跳信息流广告页」的兜底逻辑仍在（第 5、10、15… 章），属信息流体系的一部分，不是插屏弹窗。
