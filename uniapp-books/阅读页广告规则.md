# 阅读页广告规则文档

> 适用页面：`src/pages/reader/reader.vue`
> 配置中心：`src/utils/ad-config.js`
> 广告宿主/触发：`src/components/InterstitialAdHost.vue`、`RewardedVideoAdHost.vue`、`src/utils/interstitial-ad.js`、`src/utils/rewarded-video-ad.js`
> 本文档对应《电子书 App 广告位设计文档》的阅读页实现部分，并标注当前实现与设计文档的差异。

## 0. 平台与打包要求（前置条件）

| 项 | 说明 |
|---|---|
| 运行平台 | 广告原生组件仅在 **App**（Android/iOS）生效，H5 / 微信小程序不渲染 |
| 打包方式 | 需**云打包**或标准基座，且勾选 **UniAd** 模块 |
| 测试开关 | `ad-config.js` 中 `AD_USE_TEST = true` 时用 DCloud 测试位；上线改 `false` 走正式位 |
| 翻页模式 | 信息流/插屏依赖分页逻辑，**仅在 `pageFlipMode === 'horizontal'`（翻页）模式生效**；`swipe`（滚屏）模式走全文渲染，不插入广告页（`reader.vue:35` 条件分支）|

## 1. 广告类型总览

| 广告类型 | 位置 | 触发方式 | 频控 / 间隔 | 是否受免广告时段抑制 |
|---|---|---|---|---|
| **Banner（横幅）** | 阅读页底部常驻 | 进入阅读页即展示，轮播 | 常驻（≥25s 轮播，由 uni-ad 后台控制） | ❌ 当前不抑制（见 §7 待办） |
| **信息流 / 原生** | 正文内（每章中间） | 按章节规则自动插入 | 每 5 章 1 条，前 3 章不展示 | ✅ 抑制 |
| **插屏** | 全屏弹窗 | ①本章完 ②返回书架 | 每 5 章；最小间隔 45s | ✅ 抑制 |
| **激励视频** | 全屏视频 | 用户主动点「免广告」按钮 | 用户主动，`force:true` 忽略间隔 | 本身即发放免广告的手段 |

## 2. 各广告详细规则

### 2.1 Banner（底部常驻）

- **渲染**：阅读页底部菜单上方固定常驻 `<ad :adpid="AD_BANNER_PID">`（`reader.vue:39-48`，仅 `APP-PLUS`）。
- **实现说明**：uni-ad 没有独立 Banner 组件，这里用**信息流原生广告组件固定底部常驻**来模拟横幅（设计文档的 "Banner 轮播 ≥25s" 由 uni-ad 后台配置实现）。
- **免广告时段**：**当前未抑制**——即便处于免广告时段，Banner 仍展示（见 §7 待办）。

### 2.2 信息流 / 原生（正文内）

- **插入条件**（`reader.vue:752-762`）：
  ```js
  feedEligible = readerFeedAdEnabled          // 总开关开启
    && !this.isAdFree                        // 不在免广告时段
    && chapterNum > AD_FEED_START_CHAPTER    // 前 3 章（AD_FEED_START_CHAPTER=3）不展示
    && (chapterNum - AD_FEED_START_CHAPTER) % AD_FEED_EVERY_CHAPTER === 0; // 之后每 5 章（AD_FEED_EVERY_CHAPTER=5）1 条
  if (feedEligible && pages.length >= 2) {
    pages.splice(Math.floor(pages.length / 2), 0, { type: 'ad' }); // 插在本章正文中间
  }
  ```
- **插入位置**：本章正文页码的中间（`floor(总页数/2)`），避免在章节首尾与插屏/翻章断点冲突。
- **渲染**：单页一个原生 `<ad :adpid="AD_FEED_PID">`，无文字标记（`reader.vue:38-49`）。
- **前置**：`pageFlipMode === 'horizontal'`（翻页模式）；滚屏模式不插入。
- **前 3 章不展示**的含义：第 1、2、3 章正文内不放广告，从第 4 章起按每 5 章（第 8、13、18… 章）插入。

### 2.3 插屏（全屏）

两个触发点，均受免广告时段与全局互斥保护：

1. **本章完**（`reader.vue` `nextPage()`）：当当前章翻到最后一页且还有下一章时，调用
   `maybeShowChapterEndInterstitial(this.currentChapterNum)`（`reader.vue`）。内部规则：
   ```js
   if (!readerFeedAdEnabled || isAdFree) return;
   if (chapterNum % AD_INTERSTITIAL_EVERY_CHAPTER !== 0) return; // 每 5 章（AD_INTERSTITIAL_EVERY_CHAPTER=5）
   showInterstitialAd({ delay: 300 });
   ```
2. **返回书架**（`reader.vue` `goBack()`）：
   ```js
   if (readerFeedAdEnabled && !isAdFree) {
     await showInterstitialAd({ delay: 200 });
   }
   uni.navigateBack();
   ```

- **间隔保护**：`showInterstitialAd` 内部有最小间隔 `AD_INTERSTITIAL_INTERVAL = 45s`（`ad-config.js:120`），两次插屏至少间隔 45 秒。
- **全局互斥**：`ad-guard.js` 保证同时只有一种广告在播，避免插屏与激励/信息流叠加。

### 2.4 激励视频（用户主动）

- **触发**：阅读页底部菜单「免广告」按钮 → `onRewardUnlock()`（`reader.vue:136` / `:520`）。
  ```js
  if (this.isAdFree) { toast('已处于免广告时段'); return; } // 已在免广告时段内不弹
  const res = await showRewardedVideoAd({ force: true, scene: 'reader_unlock' });
  if (res.shown && res.isEnded) {
    this.adFreeUntil = Date.now() + AD_REWARD_AD_FREE_MS; // 发放 30 分钟免广告
  }
  ```
- **发奖**：看完（`isEnded === true`）后发放 `AD_REWARD_AD_FREE_MS = 30 分钟` 免广告时段。
- **间隔**：使用 `force: true`，**忽略** `AD_REWARD_INTERVAL`（5 分钟）间隔——用户可主动反复触发（设计上这是用户用注意力换权益，不做冷却）。
- **服务端校验**：开启 `AD_REWARD_ENABLE_URL_CALLBACK = true`，看完后由 uniCloud 云函数 `ad-reward-callback` 二次确认发奖。

## 3. 免广告时段（`isAdFree`）

- **计算**：`isAdFree = Date.now() < this.adFreeUntil`（`reader.vue` computed）。
- **发放**：仅由激励视频看完后写入 `adFreeUntil`。
- **抑制范围**：
  - ✅ 信息流插入（§2.2 的 `!this.isAdFree`）
  - ✅ 插屏两个触发点（§2.3 的 `!isAdFree`）
  - ❌ **Banner 不抑制**（当前实现，见 §7 待办）
- **持久化**：见 §5，跨会话/跨阅读页保持。

## 4. 频控与互斥汇总

| 维度 | 策略 | 位置 |
|---|---|---|
| 广告同时播放 | 全局互斥，单例锁 | `src/utils/ad-guard.js` |
| 插屏最小间隔 | 45s | `AD_INTERSTITIAL_INTERVAL` |
| 激励视频最小间隔 | 5min（仅对未接入的自动触发生效，见 §7） | `AD_REWARD_INTERVAL` |
| 日上限（每人每天 X 次） | **服务端**校验，前端不持久化 | 设计文档规定 |
| 章节频控 | 信息流每 5 章 / 插屏每 5 章 / 前 3 章豁免 | `ad-config.js` 常量 |

## 5. 本地持久化规则（storage keys）

为兼顾"用户体验"与"收益可信"，以下状态写入本地缓存（`uni.setStorageSync`），并在启动时恢复：

| Storage Key | 内容 | 作用 | 文件 |
|---|---|---|---|
| `ad_free_until` | 免广告截止时间戳 | 跨会话保留 30 分钟免广告权益 | `reader.vue` |
| `ad_interstitial_last_show` | 插屏上次展示时间 | 跨会话防瞬时重弹 | `interstitial-ad.js` |
| `reward_ad_last_show` | 激励视频上次展示时间 | 跨会话防瞬时重弹 | `rewarded-video-ad.js` |
| `reward_ad_uid` | 激励视频用户标识 | 服务端回调对账 | `rewarded-video-ad.js` |

**时钟防护**：
- `ad_free_until`：读取时 `Math.min(v, Date.now() + AD_REWARD_AD_FREE_MS)` 封顶，防止改时钟拉长免广告窗口。
- 两个 `last_show`：若存储值在未来（疑似改时钟），归零，避免"上次时间在未来"导致广告被长期屏蔽。

> 注：本地时间校验可被改系统时钟绕过，仅作前端兜底；硬约束（日上限、发奖）仍由服务端负责。

## 6. 与设计文档对照 & 已知差异 / 待办

| 设计文档要求 | 当前实现 | 差异 / 待办 |
|---|---|---|
| Banner 阅读页底部常驻、轮播 ≥25s | 用信息流原生组件固定底部常驻模拟 | 非独立 Banner 组件，样式由后台位决定 |
| 信息流 正文，每 3~5 章 1 条，前 3-5 章不展示 | 每 5 章 1 条，前 3 章豁免 | ✅ 符合（参数化于 `ad-config.js`）|
| 插屏 本章完/返回书架，每 5 章 | 已实现两触发点 + 45s 间隔 | ✅ 符合 |
| 激励视频 用户点按钮解锁/换免广告 | 已实现「换 30 分钟免广告」 | ✅ 符合 |
| 免广告时段应全面免广告 | 已抑制信息流 + 插屏 | ⚠️ **Banner 未纳入抑制**，待补 |
| 进门自动弹激励（首页/详情） | `showPrimaryRewardAd` 已写但**无调用方（死代码）** | 如需自动弹，需显式调用并打开 `AD_REWARD_ON_DETAIL` |
| 首页搜索按次数弹激励 | 原已实现，**已按需求移除** | 当前搜索不再弹广告 |

### 建议后续
1. 将 Banner 也接入 `isAdFree` 判断（隐藏并补偿底部布局 padding）。
2. 如需"进首页/详情自动弹激励"，接入 `showPrimaryRewardAd` 并评估 `AD_REWARD_ON_DETAIL`。
3. 上线前将 `AD_USE_TEST` 改为 `false`，并替换各广告位为已审核的正式 `adpid`。
