## ⚠️ 注意事项

### 1. H5 环境 CORS 限制（重要）

**问题**：H5 浏览器环境下，由于 CORS（跨域资源共享）限制，无法直接调用夸克网盘 API。

**表现**：点击在线阅读报错 `Invalid CORS request`

**当前解决方案**：
- ✅ **小程序/App**：正常使用，不受 CORS 限制
- ⚠️ **H5**：显示提示"H5 版本暂不支持在线阅读，请使用小程序或 App 版本"

**未来方案**：
如果需要支持 H5 在线阅读，可以：
1. 搭建代理服务器（推荐）
2. 使用 Nginx 反向代理
3. 配置第三方解析服务

详见：[CORS跨域问题说明.md](./CORS跨域问题说明.md)

### 2. Cookie 有效期
- Cookie 通常 1-2 周后过期
- 过期后需重新获取并更新配置
- 建议使用 `cookieUrl` 方式，便于动态更新

### 2. 网盘 API 限制
- 频繁调用可能触发限流
- 建议客户端缓存解析结果
- 直链有效期通常 1-2 小时

### 3. 小程序域名配置
小程序必须配置以下域名为合法域名：
- `https://drive-pc.quark.cn`（夸克网盘）
- `https://pan.baidu.com`（百度网盘）
- `https://toolset.site`（CDN，回退地址）

### 4. Cookie 安全
- 不要将 `pan-config.js` 提交到 Git
- 如果不慎泄露，立即更换账号密码
- 推荐使用 `cookieUrl` 方式，避免 Cookie 暴露在客户端

## 🐛 常见问题

### Q1: H5 浏览器报错"Invalid CORS request"

**原因**：浏览器的跨域安全策略阻止了对夸克 API 的请求

**解决**：
- 当前方案：H5 暂不支持在线阅读，提示用户使用小程序/App
- 长期方案：搭建代理服务器（详见 [CORS跨域问题说明.md](./CORS跨域问题说明.md)）

### Q2: 小程序报"Method Not Allowed (405)"

**原因**：API 请求方法不正确（已修复）

**解决**：
- ✅ 已将夸克 API 从 POST 改为 GET 请求
- ✅ 已修正请求参数格式
- 更新代码后重新构建即可

### Q3: 点击在线阅读报错"Env状态异常"

**原因**：云服务已停服

**解决**：使用新的客户端解析方案（本次更新已实现）

### Q2: 提示"未配置夸克网盘 Cookie"

**原因**：`pan-config.js` 中 Cookie 未配置或为空

**解决**：
1. 登录夸克网盘获取 Cookie
2. 在 `pan-config.js` 中配置
3. 重新构建项目

### Q3: 解析成功但下载失败

**原因**：直链可能已过期

**解决**：
- 直链有效期通常 1-2 小时
- 客户端应缓存直链，过期后重新解析
- 或直接回退到 CDN 地址

### Q4: 小程序报"不在 request 合法域名列表中"

**原因**：未配置网盘域名白名单

**解决**：
1. 登录微信公众平台
2. 设置 → 开发设置 → 服务器域名
3. 添加 `https://drive-pc.quark.cn`
4. 添加 `https://pan.baidu.com`
